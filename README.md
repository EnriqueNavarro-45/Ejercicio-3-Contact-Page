## 📌 Descripción

## 📝 Reflexión

El desarrollo de esta página web me permitió comprender mejor cómo estructurar un formulario profesional utilizando HTML. Aprendí la importancia de organizar correctamente los campos mediante contenedores y clases para lograr una presentación clara y ordenada. También reforcé el uso de etiquetas semánticas y atributos como required, que ayudan a mejorar la validación y la experiencia del usuario.

Además, entendí que el diseño visual es un elemento clave en una página de contacto. El uso de un fondo degradado, una tipografía adecuada y una correcta jerarquía de títulos contribuyen a transmitir una imagen más profesional y confiable.
